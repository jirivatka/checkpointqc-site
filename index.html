How it works

From spec to signed-off, in one place

The curated spec library is the product — browse it with no file attached, then point Checkpoint at a real deliverable and let it do the checking.

1

Browse a spec

Pick a platform and deliverable and see the exact tech spec — grouped by domain, with severity, guidance and a source citation.

2

Verify a file

Point at a real deliverable. The engine reads its metadata — codec, raster, frame rate, colour, audio, timecode — and scores it against the spec.

3

Measure it

An opt-in decode pass measures loudness (LUFS / LRA / true peak) and scans for black and frozen frames.

4

Sign it off

Auto-verified rows sit beside manual checks (textless, A/V sync, illegal levels) — then export a print-ready PDF QC report.

What it does

The checks a delivery actually needs

Everything scored against the chosen spec — no guessing, no spreadsheet, no separate tools.

📚

Curated spec library

40 curated delivery specs and growing — streamers, broadcasters, theatrical and delivery standards — each rule with severity, guidance and a source citation. New platforms land regularly through Spec Updates.

🧩

Build your own specs

Not in the library — or a house / client standard of your own? Create a custom preset with your own rules (fields, matchers, ranges). It lives under My Presets and verifies files exactly like a built-in spec.

🔍

Real file verification

Reads a deliverable's codec, raster, frame rate, colour, audio and timecode via AVFoundation, and flags every parameter pass / warn / fail. QuickTime & MP4 — ProRes, H.264, HEVC.

🔊

Broadcast-grade loudness

ITU-R BS.1770-4 / EBU R128 integrated LUFS, loudness range and 4× oversampled true peak — validated against the EBU Tech 3341 test signals.

🎞️

Black & freeze detection

The decode pass samples the picture for black frames and frozen frames, so silent delivery-killers surface before the platform's QC does.

✅

QC checklist

Auto-verified rows sit alongside manual checkboxes — textless elements, A/V sync, illegal levels — for a complete, defensible sign-off.

📄

Print-ready PDF report

A branded, per-parameter QC report with an overall verdict — the deliverable you hand to production, post and the platform.

🔄

Always current

Specs change. Optional Spec Updates keep the library refreshed as platforms revise their delivery requirements — and lapsing keeps every spec you already have.

🛡️

Clean-room & sandbox-safe

Built from scratch with no third-party or proprietary code and no external binaries — fully App Sandbox-clean and Mac App Store native.
